# FluxGit Homebrew Tap

Official Homebrew tap for [FluxGit](https://fluxgit.com).

## Install

```
brew tap fluxgit-hq/fluxgit
brew install --cask fluxgit
```

Or in one line:

```
brew install --cask fluxgit-hq/fluxgit/fluxgit
```

## What is FluxGit?

FluxGit is the approval layer for AI agents in Git. The agent proposes over
MCP; you approve the exact diff, risk level and restore point before anything
runs.

All macOS builds are signed and notarized, for both Apple Silicon and Intel.
FluxGit is in beta. Free for public repositories; private, self-hosted and
local repos need a license.

More at [fluxgit.com](https://fluxgit.com).
